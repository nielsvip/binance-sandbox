# SWITCH_MATRIX executable interdependency manual — 2026-07-29

This is the operating order for filling `SWITCH_MATRIX_TRB`. It replaces
field-by-field optimization with coherent entry → exit → reentry → sizing
experiments. The complete per-path inventory is generated by
`tools/build_matrix_interdependency_manual.py` into:

- `data/reports/SWITCH_MATRIX_INTERDEPENDENCY_20260729.json` — dependency DAG,
  invalidation rules, contracts, and every tradeable non-option path.
- `data/reports/SWITCH_MATRIX_INTERDEPENDENCY_20260729.csv` — the human/agent
  work queue with master, description, order, switching guidance, and retest
  class.

## The order that may be executed

| order | layer | establish before continuing | changing it invalidates |
|---:|---|---|---|
| 0 | data / side / account | frozen NPZ hash, completed-parent HTF, native/interpolated 5m provenance, explicit LONG or SHORT, account | everything |
| 10 | family master | exact off/on fingerprint changes; otherwise red `RECONNECT` | its sub-settings and every consuming bundle |
| 20 | entry source | at least three real entries on both discovery folds | every entry filter, exit, reentry, sizing result using those entries |
| 30 | entry filter | frozen entry control; measure whether it removes bad rather than merely many entries | all later exit/reentry/sizing results |
| 40 | exit source | same frozen entry population; profitable/top exit intent separated from emergency entry-failure diagnostics | exit filters, reentry, sizing; paired entry control must be rerun |
| 50 | exit filter | close timing and partial-close accounting | reentry and sizing |
| 60 | reentry | persistent exit-price/top reclaim remains latched until reopened | complete entry→exit→reentry cycle and sizing |
| 70 | sizing | fills, capacity, solvency, drawdown, costs and deployment | all capital metrics; signals alone may be reused |
| 80 | other guard | exact changed fingerprint and an identified action boundary | complete coherent bundle, conservatively |

Do not run layer 40 against a different layer-20/30 population and call the
difference “exit alpha.” Do not rank an exit without its reentry behavior.
Opening or closing one path changes the population seen by every path after it.

## Baseline and coherent-bundle procedure

1. Freeze key, side, account, date range, NPZ SHA, code SHA, costs, capacity and
   fold boundaries. LONG and SHORT are separate books.
2. Run the default exact baseline. A knob whose two values reproduce its
   fingerprint is red `RECONNECT`; do not sweep its children.
3. Screen whole bundles vector-first. A bundle contains its entry source,
   filters, exits, reentry obligation and sizing assumptions. It is not a bag
   of independently promotable cells.
4. Use two discovery folds, freeze the winner, then use untouched validation.
   Early-stop a bundle as soon as a discovery fold cannot clear its gates.
5. Allocate nine claims to previously positive/promising handles and one to
   deterministic exploration. Three consecutive negative/inert results demote
   a handle to the exploration lane.
6. Only strict vector survivors enter exact replay. Exact replay must prove
   fills, partial P&L, capacity, solvency, completed-parent causality, side
   separation, mandatory reentry, and the same capital/TIM metric.
7. Promotion changes only the explicit per-symbol overlay after a fresh
   no-position or controlled transition gate. Preserve the prior overlay hash
   and exact receipt for rollback.

## Invalidation is directional, but controls are cyclic

- A data, side, account, cost or capital change starts a new campaign. Every
  prior cell is stale.
- A master change invalidates every setting in its family and all bundles that
  consume the family.
- An entry change invalidates every downstream result because it changes which
  trades exist.
- An exit change invalidates reentry and sizing. It also requires the frozen
  entry control again, because a “better exit” on different entries is not an
  exit comparison.
- A reentry change requires the entire entry→exit→reentry cycle. An exit-price
  obligation may be temporarily vetoed by WT/stoch conditions, but cannot be
  forgotten.
- A sizing change requires capital replay even if signal timestamps are
  identical. Size may improve dollars; it cannot manufacture timing alpha.
- An unknown/global guard is conservative: retest the full bundle.

The JSON `retest_rules` and each CSV row's `retest_class` make these decisions
executable by a scheduler.

## Color and evidence definitions

| color | definition | action |
|---|---|---|
| red | zero real closes, same-value fingerprint, stale/wrong contract, future HTF, capacity/solvency/partial-accounting failure, reentry violation, disconnected or degenerate knob | repair/quarantine; never rank |
| gray | valid measured evidence that does not beat side-aware B&H-or-cash and the same-fold control; includes losing DC-low emergency churn | retain so it is not retested routinely; eligible only for the 10% exploration lane |
| green | current-contract exact evidence with real closes, changed fingerprint, no red failure, positive alpha over side-aware B&H-or-cash and control on every required fold, and target TIM | candidate only; still needs promotion gates |
| white | untested, incomplete, or not comparable | schedule after dependencies |

Green is not “positive P&L.” In a rising LONG book it must beat LONG B&H; in a
SHORT book it must beat side-aware SHORT B&H or cash. LONG and SHORT P&L are
never pooled.

## Fold, data and capital contract

- Frozen chronological folds: 35% discovery-1, 35% discovery-2, 30% untouched
  validation for the current bundle screen.
- HTF features use only completed parent bars. Stocks disclose whether each 5m
  bar is native or interpolated from the containing 15m bar; interpolation is
  not hidden or treated as native history.
- B&H uses the side-aware move of one $2,000 unit. Sandbox strategy capacity may
  reach $16,000, but leverage is reported separately.
- Return-on-deployment uses net fill P&L divided by **pre-cost committed fill
  notional integrated over the complete fold**. The denominator is never marked
  notional.
- Publish binary time in market separately. The current screening gate is
  65–80%.
- A per-trade percentage sum, unqualified Sharpe, levered-vs-unlevered multiple,
  or ratio with near-zero B&H is not promotion evidence.

## Rollback

Every campaign records its cohort hash, code hash, NPZ/fold hashes, overrides,
controls, receipts and live-write flags. Research rollback archives its campaign
directory and `BUNDLE_*` fleet rows. Live rollback restores the exact prior
per-symbol overlay; it never rewrites global config or mixes another side or
account.
